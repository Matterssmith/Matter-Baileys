Adaptador escrito en Rust. Hoy normaliza eventos no autenticados.
NO contiene la pila Go de whatsmeow ni un port completo.
La implementación real del protocolo requerirá auditoría de licencia,
funcionalidades, compatibilidad y tests de WhatsApp.
